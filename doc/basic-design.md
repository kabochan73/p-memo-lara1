# 基本設計書 (Basic Design)

| No. | 項目 | 内容 |
|---|---|---|
| 28 | 技術選定 | バックエンド: Laravel(PHP) / フロントエンド: Blade + Vite / DB: MySQL / 開発環境: Docker(自作構成、Sailは使わない) |
| 29 | システム構成 | `app`: PHP-FPM(Laravel本体) / `web`: Nginx(リバースプロキシ) / `db`: MySQL / `node`: Node.js(Vite dev server) |
| 30 | 画面一覧 | 会員登録画面 / ログイン画面 / メモ一覧画面(検索含む) / メモ詳細画面 / メモ作成画面 / メモ編集画面 |
| 31 | 画面遷移図 | ```<br>会員登録画面 ⇄ ログイン画面<br>ログイン画面 →(ログイン成功)→ メモ一覧画面<br><br>メモ一覧画面 →(新規作成)→ メモ作成画面 →(作成後)→ メモ一覧画面<br>メモ一覧画面 →(選択)→ メモ詳細画面<br>メモ詳細画面 →(編集)→ メモ編集画面 →(更新後)→ メモ詳細画面<br>メモ詳細画面 →(削除)→ メモ一覧画面<br>メモ一覧画面 →(ログアウト)→ ログイン画面<br>``` |
| 32 | ワイヤーフレーム | スキップ |
| 33 | 共通レイアウト | ヘッダー: アプリ名表示、ログイン中はログアウトボタンを表示 / サイドバー: なし / フッター: なし |
| 34 | UIデザイン | Tailwind CSSを使い、最低限整った見た目にする(独自デザインは作り込まない) |
| 35 | レスポンシブ設計 | 対応しない(PCでの表示を基本とする) |
| 36 | 画面項目定義 | 会員登録画面: 名前・メールアドレス・パスワード・パスワード確認・登録ボタン・ログイン画面へのリンク<br>ログイン画面: メールアドレス・パスワード・ログインボタン・会員登録画面へのリンク<br>メモ一覧画面: 検索ボックス・メモ一覧(タイトル・更新日時)・新規作成ボタン・詳細リンク<br>メモ詳細画面: タイトル・本文・作成日時・更新日時・編集/削除ボタン・一覧へ戻るリンク<br>メモ作成画面: タイトル・本文・保存ボタン<br>メモ編集画面: タイトル(既存値)・本文(既存値)・更新ボタン |
| 37 | 入力項目定義 | 会員登録フォーム: 名前・メールアドレス・パスワード・パスワード確認<br>ログインフォーム: メールアドレス・パスワード<br>メモ作成/編集フォーム: タイトル・本文<br>検索フォーム: キーワード |
| 38 | 入力制約 | 名前: 必須/255文字以内<br>メールアドレス: 必須/メール形式/重複不可<br>パスワード: 必須/8文字以上/確認用と一致<br>メモタイトル: 必須/255文字以内<br>メモ本文: 任意<br>検索キーワード: 任意 |
| 39 | 操作仕様 | 登録ボタン: 入力チェック後アカウント作成しログイン状態にしてメモ一覧画面へ遷移<br>ログインボタン: 認証成功でメモ一覧画面へ遷移、失敗時はエラーメッセージを表示<br>ログアウトボタン: ログイン状態を解除しログイン画面へ遷移<br>新規作成ボタン: メモ作成画面へ遷移<br>保存ボタン(作成): メモを登録しメモ一覧画面へ遷移<br>編集ボタン: メモ編集画面へ遷移<br>更新ボタン: メモを更新しメモ詳細画面へ遷移<br>削除ボタン: 確認の上メモを削除しメモ一覧画面へ遷移<br>検索: キーワードを入力して検索を実行する |
| 40 | 表示仕様 | メモ一覧は更新日時の降順で表示する / 検索はタイトル・本文を対象に部分一致で検索する |
| 41 | 状態遷移設計 | 対象外(メモに状態の概念はない) |
| 42 | 権限マトリクス | 未ログインユーザー: 会員登録・ログインのみ可能 / ログイン済みユーザー: メモのCRUD・検索が可能(自分が作成したメモのみ) |
| 43 | 正常時の動作 | 各操作(登録・ログイン・作成・更新・削除)が成功したら、該当画面に遷移し「〇〇しました」というフラッシュメッセージを表示する |
| 44 | 異常時の動作 | バリデーションエラー: 同じフォーム画面にエラーメッセージを表示し入力値は保持する / ログイン失敗: ログイン画面にエラーメッセージを表示する / 他人のメモへのアクセス試行: 403エラー画面を表示する |
| 45 | 空データ時の動作 | メモが1件もない場合: 一覧画面に「メモがありません」と表示する / 検索結果が0件の場合: 「該当するメモが見つかりません」と表示する |
| 46 | ローディング仕様 | 特に実装しない(通常のページ遷移のみで、非同期通信は行わない) |
| 47 | 通知仕様 | メール通知・アプリ内通知は実装しない(スコープ外) |
