# 要件定義書 (Requirements)

| No. | 項目 | 内容 |
|---|---|---|
| 11 | ユーザー種別 | 一般ユーザーのみ(管理者は設けない) |
| 12 | ユースケース | 会員登録する / ログインする / ログアウトする / メモを作成する / メモ一覧を見る / メモの詳細を見る / メモを編集する / メモを削除する / メモをキーワードで検索する |
| 13 | 機能一覧 | 会員登録機能 / ログイン機能 / ログアウト機能 / メモ作成機能 / メモ一覧表示機能 / メモ詳細表示機能 / メモ編集機能 / メモ削除機能 / メモ検索機能 |
| 14 | 機能概要 | 会員登録機能: メールアドレス・パスワードを登録してアカウントを作成する<br>ログイン機能: 登録済みの情報で認証し、ログイン状態にする<br>ログアウト機能: ログイン状態を解除する<br>メモ作成機能: タイトル・本文を入力して新しいメモを登録する<br>メモ一覧表示機能: ログイン中のユーザーが作成したメモを一覧表示する<br>メモ詳細表示機能: 選択したメモの詳細(タイトル・本文・作成日時など)を表示する<br>メモ編集機能: 既存メモのタイトル・本文を更新する<br>メモ削除機能: 不要なメモを削除する<br>メモ検索機能: タイトルや本文に含まれるキーワードでメモを検索する |
| 15 | 機能優先度 | 全機能「必須」(追加機能はなし) |
| 16 | スコープ定義 | 機能一覧(No.13)の9機能(会員登録・ログイン・ログアウト・メモCRUD・メモ検索) |
| 17 | スコープ外定義 | カテゴリ・タグ分類機能 / パスワードリセット機能 / プロフィール編集機能 / メモの共有機能 / ファイル添付機能 |
| 18 | 業務ルール | メモは作成した本人のみが参照・編集・削除できる(他人のメモは見れない) / ログインしていないユーザーはメモ関連の機能を利用できない / メモのタイトルは必須、本文は任意 |
| 19 | データ要件 | ユーザー情報(名前・メールアドレス・パスワード) / メモ情報(タイトル・本文・作成日時・更新日時・所有者) |
| 20 | セキュリティ要件 | パスワードはハッシュ化して保存(bcrypt) / ログインが必要なページは認証ミドルウェアで保護 / 他人のメモを操作できないようPolicyで認可制御 / CSRF対策はLaravel標準機能を利用 |
| 21 | パフォーマンス要件 | 特別な性能要件は設けない(同時アクセス数などは想定しない) |
| 22 | ユーザビリティ要件 | 主要な操作がシンプルで分かりやすいこと(レスポンシブ対応は必須としない) |
| 23 | 可用性要件 | 特に設けない(学習用のため稼働率などは想定しない) |
| 24 | 保守性要件 | Laravelの標準的なディレクトリ構成・命名規則に従い、読みやすいコードを書く |
| 25 | 対応環境 | PC向けのモダンブラウザ(Chrome/Edgeなど最新版) |
| 26 | 外部連携要件 | なし |
| 27 | 受け入れ条件 | 機能一覧(No.13)の9機能がすべて正しく動作すること |
