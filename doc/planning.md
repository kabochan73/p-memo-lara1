# 企画書 (Planning)

| No. | 項目 | 内容 |
|---|---|---|
| 01 | アプリ名 | Laravel Memo |
| 02 | 開発背景 | Laravelの練習のため |
| 03 | 開発目的 | 設計力を身につける(要件定義・DB設計・画面設計などの進め方を一通り経験する) |
| 04 | サービス概要 | ユーザーがログインして、メモの作成・一覧・詳細・編集・削除ができ、キーワード検索もできるシンプルなWebメモアプリ |
| 05 | 課題定義 | 特になし(学習目的のため、実課題の解決は対象外) |
| 06 | ターゲット | 不特定多数の一般ユーザー(各ユーザーがアカウントを作成し、自分のメモを管理する) |
| 07 | 利用シーン | 日常的に、思いついたことやタスクなどを随時記録・確認する場面 |
| 08 | 学習目標 | Laravelの基本的なMVCの流れ・DB設計、CRUD/認証/検索機能の実装、Feature Testによるテスト設計 |
| 09 | 開発規模 | 小規模(メモのCRUD + 認証 + 検索機能の範囲) |
| 10 | 開発スケジュール | 特になし |
